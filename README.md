# 👾 갤러가 REBORN

> 추억의 갤러그를 현대적 캐주얼 스타일로 재탄생! 자동 발사로 이동만 하면 끝!

**▶ 지금 바로 플레이** → [https://mindweaver74.github.io/galuga-reborn](https://mindweaver74.github.io/galuga-reborn)

---

## 🎮 게임 방법

1. 좌우로 이동하면 **자동으로 발사**됩니다
2. 적을 모두 처치하면 **다음 스테이지**로 진행
3. **3스테이지마다 보스** 등장
4. 적 총알이나 다이브에 맞으면 목숨 1개 감소
5. 목숨이 모두 사라지면 게임 오버

---

## 🕹️ 조작법

| 환경 | 조작 |
|------|------|
| 📱 모바일 | 화면 좌우 드래그 |
| 🖥️ PC 마우스 | 클릭 후 좌우 드래그 |
| ⌨️ PC 키보드 | ← → 방향키 |

> 발사는 자동 — 이동만 하면 됩니다!

## 🏆 점수 체계

| 등급 | 점수 |
|------|------|
| 일반 적 (빨강) | 100점 |
| 일반 적 (주황) | 150점 |
| 강화 적 (보라) | 200점 |
| 강화 적 (초록) | 300점 |
| 보스 | 1000점 + 스테이지 보너스 |

- **콤보 3회** 이상 → 점수 2배
- **콤보 5회** 이상 → 점수 3배

## ✨ 특징

- 🚀 **자동 발사** — 버튼 없이 이동만으로 플레이
- 🌀 **다이브봄** — 적이 편대에서 이탈해 플레이어에게 돌진
- 👾 **보스전** — 3스테이지마다 HP바를 가진 보스 등장
- 🔫 **무기 업그레이드** — 스테이지 3부터 3방향, 6부터 5방향 발사
- 💥 **콤보 시스템** — 연속 처치로 최대 3배 점수
- 🎵 **효과음 6종** — 발사 / 폭발 / 피격 / 보스등장 / 스테이지클리어
- ✨ **파티클 이펙트** — 화려한 폭발 + 화면 흔들림
- 🏆 **최고 기록 저장** — 브라우저에 자동 저장
