## 🎮 게임 방법

1. 화면 하단의 전투기를 좌우로 이동하세요
2. 총알은 자동으로 발사됩니다 — 이동에만 집중하세요!
3. 편대를 이루며 내려오는 적을 모두 격추하면 스테이지 클리어
4. 다이브봄 공격에 주의하며 생존하세요!

## ✨ 주요 특징

- 🤖 **자동 발사** — 조준 없이 이동만으로 플레이
- 💥 **다이브봄** — 적이 대형을 이탈해 돌진 공격
- 👾 **보스 등장** — 스테이지마다 강력한 보스 적 등장
- 🔫 **보조기 획득** — 편대 비행 보조기 획득 시 화력 2배
- 🎵 **6종 효과음** — 발사·격추·폭발 등 타격감 있는 사운드

## 💡 고득점 전략
